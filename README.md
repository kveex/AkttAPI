
# AKTT Schedule API

API для получения и преобразования расписаний Арзамасско Коммерческо-Технического Техникума в более доступный формат, работающая в связке с базой данный [PostgreSQL](https://www.postgresql.org/)


## Ссылки API

#### Получить пары группы

```http
  GET /api/schedule/student/{groupName}
```

| Параметр    | Тип      | Нахождение | Описание                                                                   |
|:------------|:---------|:-----------|:---------------------------------------------------------------------------|
| `groupName` | `string` | `path`     | **Обязательно**. Название учебной группы, регистро-независимое `(23-14ИС)` |
| `date`      | `string` | `query`    | Дата расписания в формате `yyyy-mm-dd`                                     |
| `subgroup`  | `int`    | `query`    | Подгруппа, указанной учебной группы, в виде числа `(1, 2, любое)`          |

#### Получить пары преподавателя

```http
  GET /api/schedule/teacher/{teacherName}
```

| Параметр      | Тип      | Нахождение | Описание                                                          |
|:--------------|:---------|:-----------|:------------------------------------------------------------------|
| `teacherName` | `string` | `path`     | **Обязательно**. Имя и инициалы преподавателя, регистро-зависимое |
| `date`        | `string` | `query`    | Дата расписания в формате `yyyy-mm-dd`                            |

#### Отправить PDF расписание

```http
  POST /api/pdf-upload
```

| Параметр | Тип                   | Нахождение    | Описание               |
|:---------|:----------------------|:--------------|:-----------------------|
| `file`   | `multipart/form-data` | `requestBody` | PDF файл с расписанием |

#### Добавить вебхук

```http
  POST /api/webhook
```

| Параметр | Тип          | Нахождение    | Описание                                                |
|:---------|:-------------|:--------------|:--------------------------------------------------------|
| `url`    | `text/plain` | `requestBody` | Ссылка на сервер, которому будет отправлено уведомление |
## Переменные среды

Для запуска этого проекта вам нужно добавить эту переменную среды в ваш .env файл:

`DATABASE_URL` - ссылка для подключения к базе данных PostgreSQL

Так же можно настроить программу добавив следующие переменные в ваш .env файл:

`PORT` - порт, на котором будет запускаться API

`REPEAT_DELAY_MINUTES` - Промежуток между проверками изменений в расписании на сайте АКТТ в минутах
